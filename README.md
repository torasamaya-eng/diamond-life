# DIAMOND LIFE v1.8

小学生から引退・第二の人生まで遊べる、野球人生シミュレーションです。既存の分割構造と履歴を保ちながら機能を追加しています。

## 起動

- 手軽に遊ぶ：`DIAMOND-LIFE.html` をChromeまたはEdgeで開きます（通信不要）。
- 開発・安定した記録保存：Node.js 20以上で `npm start`。http://127.0.0.1:4173/ にアクセスします。
- 依存パッケージのインストールは不要です。分割版の `dist/index.html` はHTTPサーバーから開いてください。
- 更新後は `node build-single-file.mjs` で単体版を再生成します。単体版を直接修正しません。

## 操作と保存

メニューは「進行」「成績」「キャリア」の3つです。右上からニューゲームを始めます。投手／野手、右・左・両投げ、右・左・両打ち、守備位置、スタイルを選べます。「すべてランダム」も選べます。

全ての保存・読込機能を削除しました。現役・引退後とも記録はメモリ内のみで、ページを閉じる・更新する・ニューゲームで失われます。旧保存データの読込も行いません（ブラウザ内の旧データ自体は削除しません）。

作成時の並びは投手→野手→ランダム。野手は内野・外野・捕手を選び、内野だけ一・二・三・遊を選択します。外野は左・中・右を自動決定。スタイルはバランス→アベレージ→パワー→ランダムの順で、韋駄天・守備職人は「その他」に残しています。

## 主な仕様

- 小学6年→中学3年→高校3年→国内大学・海外大学・社会人・独立・国内プロ。大学への再入学はできません。海外大学の活躍によって海外球団のドラフト指名もあります。
- 中学4進路・高校4校。出場機会と全国大会への近さに長所・短所があり、推薦は能力とU12/U15の実績を考慮します。
- 天才は約30人に1人。小学生で示唆があります。早熟、学生覚醒、プロで開花、挫折、平凡など8種類の成長傾向があります。
- 野手はレギュラー・控え・守備固め・代走。打数や守備・走塁貢献が変わります。DHはプロ・社会人でチーム判断により起用します。学生はDHになりません。
- 投手スタイルは本格派・技巧派。高校卒業後は先発・中継ぎ・セットアッパー・抑え・控え・敗戦処理に起用され、希望を出せます。
- 一軍／二軍の成績を別々に記録。育成契約は二軍限定で、能力と実戦経験によって翌季に支配下昇格します。昔の区分不明な成績は推測で分割しません。
- 打数・得点圏打率・四球・死球・三振、投手の登板・与四死球・失点・自責点・被安打・被本塁打を表示。率は分母から合算します。旧版で未収集の詳細は「—」。簡易WARは画面と新しい査定から除外しています。旧記録の値は互換用に保持します。
- 故障は7日程度から600日程度。翌季まで離脱が続く場合があり、一軍・二軍・学生大会の出場を減らします。故障発生のうち約3.5%が重傷で、能力低下、さらに少数は引退につながります。故障の種類・日数は設定データで変更できます。
- 生涯年俸と出来高を別々に集計。複数年契約には約45%の確率で、毎季の達成条件付き出来高を提示します。
- FAは実績次第で複数球団から打診。年俸・期間・レギュラー確約・将来のコーチ就任保証を比較できます。契約更改にFA／ポスティングの残年数を表示。
- トレード通知には実在するゲーム内球団と契約提示を用意し、交渉画面でも同じ条件を表示します。通常の通知は年1.2%、下降時8%、3年の間隔を空けます。ポスティング拒否時は達成課題を提示します。
- 海外球団は成績低下に厳しく、自由契約後は成績に応じて国内球団から復帰オファーが届きます。
- 任意引退が可能。上限は50歳のシーズン終了です。衰えたベテランには先に指導者転身を打診し、続行して回復しなければ自由契約になることがあります。
- 引退後は監督・コーチ・高校野球監督・解説者・タレント・YouTuber・指導者などの物語をランダム生成。同じプレイ中は一度生成した物語を閲覧できます。登録者100万人の達成は一生に一度だけです。球団を渡り歩く、優勝、名将、解任、辞任などがあります。
- WBCと五輪は開催年だけ選考。前年成績・出場量・故障状態を考慮し、招集への参加／辞退を選べます。成長・海外評価の利点と、欠場・調整不足のリスクがあります。
- 監督打診は同一プロ球団一筋10年以上かつ活躍7年以上に限定。コーチ経由の就任・現場復帰にも同じ条件を適用します。海外大学から直接プロ入りした選手は、自由契約後の国内オファー確率・球団数・年俸を優遇します。
- タイトル年は得票加点と高確率の監督推薦でオールスターに選出されやすくなります。年単位進行のため確定した年間成績で判定します。
- オールスターは票数・部門順位・年齢・球団を記録。受賞歴は独立欄をなくし、プロ通算成績の「獲得タイトル」に年齢と詳細数字を表示します。引退画面の末尾にキャリアハイがあります。
- 名球会は国内プロの初出場年を起点に日米通算2000安打・200勝・250セーブ。独立・二軍・代表成績を除外。特例入会は未実装です。永久欠番には同一球団での長期実績が必要です。

## 年俸の参考資料とモデル

2026年9月22日に、指定された[グラゼニ.com](https://www.gurazeni.com/)の推定年俸を参照しました。[牧秀悟の推移](https://www.gurazeni.com/player/1988)に掲載された1300→7000→1億2000→2億3000万円と、[DeNAの年俸分布](https://www.gurazeni.com/team/6)を参考に、若手初活躍・実績の積み重ね・主力・育成の価格帯を調整しています。実在の交渉結果を正確に再現するモデルではありません。

出場量、出塁・長打・得点圏・三振・守備・盗塁、投手の投球量・防御率・四死球・WHIP・被本塁打・S/Hを独自査定に使用。契約年数内は基本年俸を固定。海外は固定為替1ドル150円を基準とする架空モデルです。

名球会の参考：[公式入会規定](https://meikyukai.jp/regulation/)。

## 拡張する場所

| ファイル | 役割 |
| --- | --- |
| `dist/src/data.js` | 学校・球団・進路・大会周期 |
| `dist/src/profile.js` | 投打・スタイル・守備位置・起用・背番号 |
| `dist/src/archetypes.js` / `growth.js` | 成長傾向・能力変化 |
| `dist/src/stats.js` / `levels.js` | 詳細成績・通算計算・一軍二軍 |
| `dist/src/health.js` | 故障の種類・期間・後遺症 |
| `dist/src/finance.js` | 年俸・一軍追加報酬・出来高支払 |
| `dist/src/contracts.js` | 年俸査定・契約期間・参考資料 |
| `dist/src/market.js` / `lifecycle.js` | FA・トレード・ポスティング・雇用 |
| `dist/src/draft.js` / `scouting.js` | 国内・海外ドラフト・学校推薦 |
| `dist/src/national.js` / `youth.js` | 代表選考・参加判断・年代別世界大会 |
| `dist/src/awards.js` / `afterlife.js` | 表彰・名球会・引退後の物語 |
| `dist/src/engine.js` / `events.js` | 進行と拡張フック |
| `dist/src/storage.js` | 履歴データの検証（保存機能なし） |
| `dist/src/ui.js` / `numbers.css` | 画面・スマホ表示 |

既存IDは履歴の互換性のため保持してください。数値調整後は `npm test` を実行します。検証内容は `VERIFICATION.md`、変更履歴は `CHANGELOG.md` にあります。
